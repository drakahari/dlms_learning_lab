# Complete directory handovers

Two distinct LPIC-1 assignments follow the existing file, permission, creation-mask
and search progression. Library → LPIC-1 → **Complete directory handovers**.

| Stable ID | Practical work |
| --- | --- |
| `lpic1-tree-private-stage` | Inspect another user's complete source tree; create an owner-private independent copy and set future private defaults while retaining source content/access and unrelated files. |
| `lpic1-tree-verified-retirement` | Diagnose an incomplete handover, restore missing hidden/nested content and permissions, then retire only the old project while protecting its similarly named current sibling. |

Introduction teaches the mechanism before assessment, using separate `/practice`
paths and worked commands. Try example offers Insert command without execution,
actual terminal output, specific observations, check/retry and its own reset.
Assignment keeps four complete requirements visible above the working terminal;
guidance, references and a revealing worked approach remain optional. Challenge
keeps the full independent work and hides unsolicited lessons. No canned terminal
success, exact recipe matching, new language evaluator or dependency was added.

The private-copy task accepts either recursive copy or an equivalent sequence of
mkdir/individual copies. The retirement task accepts individual repairs or a
complete verified rebuild. Missing hidden files, omitted empty folders, incorrect
mode/owner, extra scratch trees, changes to protected sources/unrelated data and
early deletion with incomplete transferred data fail. Changing umask after copying
does not repair an existing permissive copy. Current state is regraded after edits.
Sequence is taught as a safe method, not falsely inferred from an action log.

See [subset and primary references](RECURSIVE_TREE_SUBSET.md).103.3remains Partial
practice: multiple-source/merge behavior, terminal globbing, general find predicates,
cpio/dd/device work, compression and full GNU flags are not implemented here.
