text before any choice. A different named example demonstrates the actual
comparison and backup-copy roles. Guided practice uses the existing terminal,
read-only virtual-file inspector and compact native per-file review. Refresh the
supplied metadata, review and choose, then explicitly apply and inspect. Review
alone changes no files; practice has independent state and earns no assignment
credit. Assignment retains the full independent task and intentional conflicts.
No required choice is filled by default. Challenge retains independent work.

Comparison columns stack at narrow widths. Controls use existing font-derived
heights and shared spacing. Stale drafts disable Apply and offer Review again;
load never applies work automatically. Feedback names the differing virtual
configuration or missing protected software. Actual state, not a selected menu
or saved success flag, determines completion. Removing required viewer software
invalidates success and reinstalling it can restore the outcome.
