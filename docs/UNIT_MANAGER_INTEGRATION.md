## Fixed assignment and safe authoring actions

workspace Definition including the exact original state, typed current/fresh
requirements and explicitly named preservation. Pack validation requires exact
initial equality, a valid definition, distinct valid unit_manager_teaching and
reachable declared reference work; an already solved assignment rejects. A
valid-but-nonseparate example rejects even if its actions reach all outcomes.

The internal `unit-manager ` plus JSON EditAction prefix exists only for pack
reachability/testing. It has a1.5MiB whole-input cap before parsing/trimming and
bounded typed maps/fields. Native UI must call typed helpers; this is not
systemctl/Linux syntax and must not be shown as an executable command example.
Raw engine execution offers only bounded help/show. Mutation requires a matching
validated Goal and exact immutable Inventory context. A Registry descriptor never
executes its identifier as a host path. Unknown keys/actions/targets fail without
partial publication. Core job failure can still be an honestly published typed
result; an action returning a report does not mean the assignment succeeded.

The larger reference-string allowance applies only to this state kind (and the
existing ACL exception). Other pack limits remain unchanged. Whole-pack input

every maximum-size combination fits that outer container. No oversize content is
silently shortened.
