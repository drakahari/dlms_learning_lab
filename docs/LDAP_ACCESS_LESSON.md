## Meaningful work

Introduction teaches target entries/attributes, caller matching, rule order and
atomic changes, with a complete separate workshop policy. Try example starts with
an overbroad first rule: inspect a forbidden mail update, repair the editor, then
verify a denied combined request and a legitimate nested-person request. Assignment
requires self contact updates, an exact desk identity allowed description only,
protected Archive/Service branches and unchanged state after any denied request.
Answers stay behind optional help. Established callers are supplied by the lab;
the edited policy does not perform a fresh Bind or change authentication.

Each scope has three different sample directories and43actual requests in total.
These are deterministic behavior cases, not43authored labs. Every request starts
with its own original directory. Results compare the complete resulting state;
all fields of a denied combined Modify must remain unchanged. Denying everything,
allowing everybody, matching only direct children or treating uid as a full name
fails. Equivalent supported caller ordering, explicit stop, dn.base alias and
read fallback may pass when every required write outcome is correct.
