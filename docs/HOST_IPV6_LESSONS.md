state rather than command spelling. Alternate unused addresses, metrics and supported
host-route repairs pass. A broad prefix may still reach a nearby peer: feedback
separates that working path from the wrong mask. A more-specific exception wins
before the default; a link-local gateway's device matters. Removing a protected
route clears current success. IPv6 has no broadcast/subtract-two rule.
