# Original client seed: teaching and native editor contract

This additive adapter is only for existing State::Network/Goal::Network. It does
not replace the original model with Ipv4Routing, add packet or host execution,
change scenario IDs/versions/goals/initials/solutions or add authored labs.
Baseline73777e0 has113 labs; this adapter adds none and makes no objective
promotion or evaluator revision.

The original seed gains skippable Introduction → separate client practice → full
Assignment. The native editor has address, prefix and default gateway; Apply
validates all fields on a scalar candidate before publication. The original
terminal solutions remain supported. ip addr set remains a disclosed simulator
shortcut. ip addr/ip route/ping give compact educational output, not full
iproute2/ICMP. The supplied router LAN plan is given context, not discovered by
a real ip addr command. A local reply alone does not establish the remote goal.

Practice uses198.51.100.150, router198.51.100.129/27 and target203.0.113.90. A
wrong .130 next hop leaves the address/mask correct but breaks the remote path;
restoring .129 repairs it. Fill/Insert only edit practice inputs. Apply/Run are
explicit; Check recomputes existing model outcomes. No action history, output
string or checked flag earns assignment credit. Assignment and practice use
separate raw fields/terminal/transcript, identity-pinned fixture and widget IDs.

Client stores only the six scalar Network fields. Draft raw byte limits are
address64/prefix16/gateway64, command4096. Example actions<=12, concepts<=6;
custom sequence readers reject excess before decoding the extra body. Practice
transcript<=32entries,<=8192bytes/entry,<=128KiB aggregate. Metadata/string bounds
are checked before cloning or replay. JSON remains under the existing2MiB pack
and16MB progress envelopes. Raw invalid fields are preserved without applying.
The assignment’s supplied router/LAN prefix/target are pinned against its original
scenario in current-credit checks and decode; editable address/prefix/gateway
remain repairable. Exact authored practice fixture is pinned during decode; legitimate evolving
editable values may coincide with assignment values. Immutable router/LAN/target
remain fixed within practice. Save validates kind/bounds; catalog-aware decode
additionally checks exact authored fixture origin. This is not tamper-proof
signing or a general plug-in platform.

Workspace1 gains optional client_draft/client_learning; absent fields remain
absent during read and preserve old current-state credit. New attempts open
Introduction. Existing attempts first upgraded open Assignment without changing
answers/transcripts/hints/steps or shell6/7/8 history. Explicit unapplied client
draft divergence clears current credit; a missing draft does not. Old terminal
mutations refresh only formerly clean client drafts; unfinished edits survive.
Selected Reset affects only this seed. Restore returns to library; relaunch
prepares missing practice metadata without overwriting saved work. DNS/Mount
teaching/pending changes remain separately owned and are not included here.
