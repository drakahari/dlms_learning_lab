The NAT-only ephemeral LRU owns at most 16 entries, each charged at most 4 MiB,
with a 16 MiB aggregate cap (including a fixed 512 KiB reservation for at most
1000 bounded activity-ID/boolean frame results and one selected fallback report). A streaming serializer counts string bytes S and
value/key/collection tokens N before any input snapshot clone, charging
`S + 128*N + 4096`, plus a reserved 32 KiB/128-token result. Eviction precedes
cloning. Misses call the unchanged authoritative progress helper; hits use borrowed
state, origin, Definition and exhaustive workspace comparisons without calling
Draft.valid/admitted/same_assignment/current_nat_checks or serializing inputs.
All shared history occurrences are charged and compared completely. Every foreign
typed family presence prevents a cache snapshot and receives authoritative
admission feedback. Shared historical/scalar metadata is preserved and is not a
NAT grading credential. Invalid oversized data is never copied into a cache key.

Storage availability is an optimization, not a predicate: valid uncacheable data
still receives the authoritative fresh result. Each library render prepares that
result once per started NAT activity, shared by counts, filters, advisory course
readiness and cards; selected workspaces evaluate after their edits/actions. The
bounded fallback may run the backend's at-most-68 shape-specific calls (hard cap
128, at most four trial copies) each rendered frame. It does not own an unbounded
snapshot. A Check/action in a frame with changed inputs may legitimately evaluate
again; the once-per-frame promise applies to unchanged library lookups and never
justifies stale green feedback. Removed activities evict their retained entries.
