## Supported behavior and limits

This batch reuses the existing parser and virtual Linux-host model. Supported
`ip -4/-6 address` and route operations affect in-memory facts; no subprocess,
host file, socket, network target or service is used. One primary address per
family/interface is modeled; remove the exact old address before adding another.
The supplied link-local next hop is scoped by device. Neighbor discovery,
SLAAC, DHCPv6, automatic address generation, real packets/ICMP and multicast are
not implemented here. IPv4 /31 and /32 host configurations remain excluded.
IPv6 subnet-router anycast is excluded as a workstation choice, not broadcast.
