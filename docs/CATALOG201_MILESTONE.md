## Two practical additions

- **Explain exact snapshot drift:** compare two complete bounded text files,
  including final-newline differences, preserve them, and distinguish useful
  drift from input trouble. Learn explains why ordinary command capture loses
  final newlines and how a checked marker or line reconstruction preserves them.
- **Review and apply a protected rollout:** validate a whole finite plan before
  predictable refusals can write files, preview or apply changed targets, retain
  independent old-current rollback and preserve unchanged rollback and inputs.

Each task has prerequisite teaching, an unrelated editable ungraded example,
full independent assignment, progressive guidance,12 deterministic cases and
supported alternatives. Negative cases expose normalization, hardcoding, path
conflicts, failure priority and premature publication. This is final-state
practice in bounded UTF8/nonNUL virtual text; no binary cmp, atomic publication,
real races/permissions/locks, or Stop/resource-failure rollback is claimed.
See [the unit guide](SHELL_SNAPSHOT_ROLLOUT_DRAFT.md).
