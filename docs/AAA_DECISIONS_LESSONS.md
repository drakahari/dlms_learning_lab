## Fidelity and grading

A named training service is an explicit metadata directory, not a real RADIUS,
TACACS+, LDAP, network-server or cryptographic implementation. Case-sensitive names
are this fixture's declared behavior. Availability is a supplied trial condition,
not an observed timeout. Actual virtual incoming IPv4/source/protocol checks occur
before identity evaluation. No host command, service, account, file or network
activity is exposed through learner input. Only supplied training words are used;
they are saved lesson text, not personal credentials or encoded Cisco hashes.

Each lesson checks the local profile inventory, six incoming cases and eight
identity/authorization cases across all sixteen supplied VTY lines. Outcomes
include the responding method, actual identity and resulting local level. An
all-local bypass cannot earn central-authentication credit even if its words
are changed to resemble central values. Broken paths, unsupported syntax or an
earlier policy block cannot satisfy a credential refusal. Missing, excessive or
surplus profiles and broken local recovery produce specific partial feedback.
Supported equivalent record order, line grouping and source-rule decomposition
pass. Only declared fallback words are authentication requirements; unrelated
valid local profile placeholder words are not exact-string answers.

Edits clear current success and trial output. Source-held checks recompute from
bounded applied state, rather than trusting saved success flags. Separate drafts,
malformed unfinished work, favorites and selectors survive compatible save/restore.
Transient observed output is not imported as new execution. Reset affects only
the chosen scope. Existing IDs, scenario/unit objects, drafts and completions stay
unchanged; these lessons add new requirements without inventing old mastery.

Accounting, remote authorization attributes, command authorization, protocol
configuration/interoperability, guessed defaults and actual equipment remain
unimplemented. The unit does not complete5.8, a certification track or exam
preparation, and does not claim vendor endorsement.
