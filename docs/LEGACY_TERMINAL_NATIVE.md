# Original Unix/Logs native acceptance controller

Source proposal, 2026-10-25. The controller and five new checks are uncompiled
and unrun at this checkpoint. No actual render, novice, accessibility, startup,
cold-reopen or other-platform acceptance is claimed.

`DLMS_SMOKE_STAGE=legacy-terminal-teaching` selects the private28000–28999
smoke range. The three IDs are the existing normal permissions, traversal and
Logs lessons. They are looked up by ID, never by catalog position; nothing is
appended to the catalog. Existing DNS, PTR and other controllers are unchanged.
Normal startup ignores this entry point.

A single bounded plan opens each actual library Start/Continue card. A new
attempt must show its Introduction. In the independent practice, one actual
Insert action must fill only the command: the practice snapshot/transcript and
assignment State/transcript/command must remain exact. Run then executes through
the normal simulated terminal. The remaining annotated reference, experiment
and repair commands are manually typed through the same field and Run button.
Checks compare actual current practice outcomes and confirm no assignment credit.

The full assignment exercises its initial wrong state, a partial repair and its
existing reference. An alternate uses ownership/private modes for access tasks
and direct grep for Logs. A later command removes write/search or selects an
overly broad log result; current completion must disappear before another Check
click. A typed repair restores it. Read-only inspection must retain success.
Neither command history nor a checked display flag grants credit.

The reference strings are trusted author-provided test inputs, not novice work.
The controller never calls the execution engine, replaces an applied State or
installs a solved fixture. The alternate strings are explicit finite test plans
reviewed against the unchanged original models. Actual typed text and the latest
normal transcript are checked after Run; inspections check their returned output
rather than merely finding a word in the echoed command.

Light150 and Dark200 typing covers both windowed and full-screen views. The
requested zoom and wide/narrow viewport must actually settle within30 attempts;
a requested window size alone is insufficient evidence. Context geometry, zoom
and pixels-per-point are read before temporary-data closures. All clicks use the
shared bounded visible-control helper and finish a dispatched click before
requiring a control that may have disappeared.

Challenge must hide teaching tabs and assistance. Different unfinished practice
and assignment command drafts are typed but not executed, then saved and read
back with the existing16MB bounded reader. Portable loaded values and actual raw
migration receipts are checked separately. Real Back/filter/Continue navigation
must retain the complete selected attempt except its legitimate visit timestamp.
Reset Cancel must preserve it exactly; Confirm must restore only the selected
assignment and example, leaving other attempts and favorites unchanged. The
assignment is then completed again through typed Run actions.

The only additional product instrumentation is an optional measured first
feedback-label rectangle for the three legacy lessons. Existing report labels,
widget IDs, drawing order, models, Goals, commands, teaching metadata and grading
remain unchanged. Practice already exposes actual check-row rectangles. Feedback
photos require the current measured label and reveal it through the main viewport
before capture. No invented panel height or off-screen click is accepted.

Finish verifies all three actual current goals, announces its precise scope once
and holds the stage while requesting asynchronous Close. All profiles, captures,
logs and measurements belong to the private guarded runner and stay ignored.

Prospective checks cover the normal plan/bounds and all four large-text/window
combinations, an actual geometry phase plus bounded failure, click phase2 after
controls disappear, actual Insert/Text/Run/check phases on each normal example,
and unsolved Finish rejection with repeated asynchronous Close retention.
The next gate requires root review and an explicit sole-heavy-slot grant:
MAIN runner focused `legacy_terminal_native_` bin tests, affected `legacy_native_`
UI checks, all-target Clippy/formatting and an identified binary. Actual native
execution remains a separate root-owned grant.
