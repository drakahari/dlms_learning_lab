## Disclosed profile

Real parsed/evaluated `require "vacation"; vacation ... "reply message";` supports
`:days`, `:subject`, `:from`, `:addresses` and `:handle`, with duplicate-option errors.
Default interval7days; this site clamps requests to1–365days. One day is86400virtual
seconds. Plain quoted strings only; MIME, `:mime`, `:seconds`, unsupported extensions
and unsupported header/address forms diagnose honestly. Existing comparator,
address, envelope, filing, keep/discard/stop, forwarding and strict refusal policies
continue in this profile. Vacation does not cancel implicit keep or stop later rules.
Two executed vacation actions fail even if the first is suppressed; mixing vacation
and reject also fails under this site's disclosed policy. Filing/keep/redirect/discard
can coexist. Effects and reply history roll back together on any message fault.

One simulated user has a primary bare dot-atom address and at most16aliases.
`:addresses` has at most32bare dot-atom values; `:from` is a bare mailbox. A reply
uses the actual envelope return address. Supported visible recipient fields
(To/Cc/Bcc/Resent-To/Resent-Cc/Resent-Bcc) must match a known user/alias, final
delivery recipient or additional address. Visible From alone does not choose the
reply recipient. Local-part comparison is exact, domain comparison ASCII-insensitive.

The policy suppresses null return paths, self-replies, configured unattended sender
patterns, seven standard List-* fields and bare Auto-Submitted values other than no.
Precedence bulk/list/junk suppression is a conservative site heuristic, not a universal
RFC requirement. Comments/parameters in Auto-Submitted, encoded/multiline headers,
full MIME and more complex mailbox grammar remain unsupported. Postmaster is not
assumed to be an unattended address. No full delivery routing graph or server exists.

A logical reply includes sender/recipient, body, subject (explicit or Auto: plus the
original, or Automated reply), Auto-Submitted: auto-replied, and bounded plain
Message-ID/References threading. This is not wire-format generation or an assertion
of production autoresponder conformance.
