## Meaningful task

Repair two supplied starter text files and their distinct permission modes,
remove one declared draft note, then create a requested account and home. Eleven
typed state predicates compare both template and copied home, absence of the
excluded note, account/group records, numeric ownership and full preservation of
unrelated accounts, homes and templates. Choosing another unchanged skeleton or
creating only a record cannot pass. Native Save/Remove edits are bounded typed
actions; account creation and investigation remain actual simulated terminal work.

Introduction teaches copy-once behavior, saving before creating, text/mode/owner
differences, hidden filenames, record/file inspection and safe trial recovery.
The worked harbor/Lumi case differs from the north/Rhea assignment. Guided
practice edits its own template, creates a home, changes the source again, reads
both paths and repairs the example. Assignment source starts intentionally wrong;
no constructor fills the authored reference or grants credit. Required standard
file text is stated as the task specification, not an executed profile solution.

The optional editor uses the shared aligned controls, a bounded multiline editor
and one selected-file Save/Remove action. Pending drafts, saved source and copied
homes are separate. Invalid drafts survive retry/resume and invalidate current
success; failed Save leaves applied state intact. Requested help can reveal native
reference changes. Old account lessons without this capability retain their UI.
