## Actual assignment and teaching

Reconcile just `log_level=` and `format=` lines in a mixed plain-text virtual
configuration. Preserve operator comments, spacing, literal text and ordering;
remove duplicate owned keys, build the complete desired file, preview safely,
apply only when different and report an already-current input honestly. Validate
all arguments and missing input before changing anything. Protect every unrelated
file and leave no extra files. The editable starter intentionally writes too early,
erases operator content and always reports Updated; it requires real repair.

Introduction teaches line preservation, candidate construction, exact comparison
and convergence. Its separate `report.conf` example uses style/layout and calls
its helper twice within one evaluation: Updated, then Unchanged. Guided actions
change the second request, then deliberately remove `IFS=` to diagnose damaged
spacing even when messages look correct. Independent assignments retain the editor,
Run script, Stop, individual case comparisons and optional hints. Examples never
earn assignment credit and their drafts remain independent.

The format is deliberately defined: only exact prefixes match. Lookalike case,
leading spaces or spaces around `=` remain literal unmanaged lines. Each retained
record receives LF, including a final nonempty record originally lacking it.
This is not a general INI or shell-configuration parser. Full output/status/final
file maps are graded over12deterministic cases, including errors and boundary text;
multiple supported implementations pass. Same-byte rewrites are equivalent at the
observable final-state level: no write-count, mtime, crash/atomicity/locking or
Stop-rollback guarantee is taught or claimed.
