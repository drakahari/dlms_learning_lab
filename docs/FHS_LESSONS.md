## Disclosed limits

These are four directory-role and active-source exercises, not all FHS or full
104.7 coverage. locate/updatedb, which/whereis/type, executable PATH resolution,
other major hierarchy branches and distribution-specific policy remain open.
Configuration uses the stated site policy; /usr/local/etc is also a legitimate
local configuration location. Supplied apps are stopped, files are small UTF-8
fixtures and only their delegated subdirectories are writable by Alex. Parent
system directories stay protected. No sudo, actual installation/service, live
database migration, shell expansion, host filesystem or real utility runs occur.
Private-file exclusivity is assessed only in the named exact destination sets,
not every possible extra virtual location. Native checks are developer evidence,
not independent novice, screen-reader, complete keyboard-only, physical-device
or Windows/macOS/Omarchy acceptance.
