# Trace branch, small-office and hosted paths

These two source-bound CCNA v1.1 work orders follow campus architecture.
Each has an introduction, a separate guided topology and an independent
assignment. The solver traces selected links in a small graph. A printer,
workstation or hosted application can be an endpoint. Only supplied gateway
and carrier nodes can carry a path between other devices.

## Branch and carrier outages

A branch task offers two possible connections over each of two carriers.
Both connections over the same carrier share its stated outage. Check which
circuit group goes unavailable, attach an independent link and trace both
specified failures. The budget counts all optional links, including an
unapproved visitor link. The assignment grades both forward and reply
connectivity and preserves the visitor separation.

## Local and hosted service

A separate studio task has a local printer and an independently hosted order
desk. The printer stays reachable inside the office under the supplied WAN
uplink failure. The hosted service must remain reachable through either
supplied carrier failure. Tests also exercise missing links, a disconnected
printer, excess options and unapproved visitor reachability.

Links are structural adjacencies already ready to forward. Actual router
configuration, routing decisions, load balancing, packet delivery, ISP
outage behavior, physical circuit diversity, public cloud provisioning and
service health are outside the simulator. All endpoints are supplied virtual
records. No network or service access occurs.
