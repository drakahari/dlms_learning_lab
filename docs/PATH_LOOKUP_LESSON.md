## Meaningful work and teaching

A supplied worker finds an older eligible `reportgen` before its required copy.
Learners edit a setup script to repair the worker’s inherited search, retain
`auditprobe`, preserve all other settings and files, and keep a separate token
report correct. Six deterministic samples change tool locations and token data;
three start with exported PATH and three without PATH. A fixed first-case answer
cannot satisfy the other provider identities. The intentional starter selects
an older provider and is not solved.

Introduction teaches ordered search, quoting/export, existing export attributes,
file execute versus ancestor search permissions and the readonly directory policy.
The worked gallery uses different tool names, paths, two samples and a different
lookup profile. Three practice actions run it, put an old provider first, then
restore a valid alternative order. The base same-name artifact is nonexecutable,
so that alternative is a real permission skip rather than a waived answer.
Assignment requirements remain independent and do not reveal a canonical PATH.

The native page opts into an actual lookup table, a supplied metadata inventory
and optional search traces only for this activity. Expected provider rows appear
only in Introduction/practice. Actual results, directory policy and the separate
child report are distinct. Old environment pages retain their labels and layout.
Edits clear results and current credit; example work cannot complete assignment.

## Implementation and boundaries

See [the supported subset](PATH_LOOKUP_SUBSET.md). A new optional typed Plan is
bound to the authored Task; the setup VM’s actual inherited child PATH feeds the
pure resolver. Only PATH’s exact-string comparison is replaced by outcomes. Its
export attribute, every other required setting, report/status and protected file
remain checked. Allowed alternative strings, duplicate entries and safe suffixes
can pass. An old readonly directory may satisfy directory policy while selecting
the wrong provider; those are deliberately separate checks.

No selected artifact is loaded or executed. The fixed child source is a separate
in-process environment-report script. There is no host shell, filesystem lookup,
subprocess, network or service change. Lookup is bounded and charged within the
existing job budget; Stop between stages cannot publish a partial record. Old
None Task/CaseRun fields remain absent in serialized data; evaluator19 and progress
schema are unchanged. Saved observations need actual rerun for current credit.
Catalog-aware save rejects source/observation erasure or mutation before replacing
existing data.
