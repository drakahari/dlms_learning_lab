# Named-map lookup and reconciliation unit

The source catalog has **279 labs across 84 units** (2026-11-05). These two distinct
assignments follow indexed arrays and text records in the agreed Bash/Shell path.
They do not complete the path or imply exam preparation or mastery.

| Lab | Practical assignment | Prerequisites |
| --- | --- | --- |
| `shell-map-lookup` | Build a changing named catalog from supplied keys/values; answer ordered, repeated, missing and blank requests. | `shell-array-priority` |
| `shell-map-reconcile` | Validate bar-separated records, retain the last accepted value per key, preserve empty values/final EOF records, and report honest request/distinct/rejection counts. | lookup, `shell-text-capstone`, `shell-preserve-lines` |

Each lesson has 12 deterministic cases, a separate worked example with different
values, contextual guided changes, an independent unsolved starter and optional
progressive hints. Introductions teach supplied versus created variables, labels
versus positions, quoted lookups and the empty-key guard. Reconciliation also
teaches separator validation, EOF handling, rejected rows and assigned-key count.
Empty-value tests are not advertised as general membership tests; map iteration
order is never required. See [supported semantics](SHELL_ASSOCIATIVE_SUBSET.md) and
[fixed reference evidence](SHELL_ASSOCIATIVE_REFERENCE.md).
