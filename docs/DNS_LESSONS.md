1. Add a dual-stack service host: author A and AAAA records without deleting existing hosts or nameserver evidence. Teach names, record types, TTL seconds/IN, absolute final-dot syntax and save versus publication before assessment.
2. Repair an alias loop: inspect CNAME and address queries, retain an alias path to the intended canonical host, and preserve other records. Equivalent supported intermediate CNAME paths may pass; replacing the alias with a copied address must fail.
3. Restore primary/backup mail discovery: repair canonical MX targets, preference values and each host's own address data while preserving web records. Lower MX preference is preferred, but DNS alone cannot prove SMTP delivery or reachability.
4. Retire an obsolete address safely: edit a multi-address RRset while retaining both required active addresses, the other address family and an unrelated host. Case/order/duplicates do not create distinct records or delivery guarantees.
5. Publish a primary change to a stale secondary: diagnose equal-serial mismatch, choose any serial actually newer under RFC1982, save/reload and update; preserve unrelated records. No real transfer packets, timers or secondary-server configuration claim.
6. Handover capstone: combine host/alias/mail repair, nameserver preservation and consistent primary/secondary publication. Substantial independent task, with no unsolicited Challenge solution.
