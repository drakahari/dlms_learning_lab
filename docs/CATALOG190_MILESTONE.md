## Four implemented assignments

`ccna-ntp-client-chain` configures a relay and two branches without bypassing the
relay. `ccna-ntp-cycle-repair` diagnoses mutual dependency and an unknown upstream.
`ccna-ntp-asymmetric-delivery` distinguishes a delivered request from a missing
reply. `ccna-ntp-policy-handover` replaces unhealthy sources while preserving
downstream and peer associations. Each accepts two tested alternatives beyond
its reference plan and rejects the authored wrong/partial approaches.

Introduction teaches the prerequisites before assessment; the separate example
uses different addresses and persists independently. Native device selection,
bounded command entry, aligned topology cards and adjacent Run/Check feedback
keep the full task visible. No learner command reaches a host shell or network.
Hints are requested one at a time; the worked approach and technical references
are separate disclosures. Navigation helpers become native selection instructions.

See [the lesson guide](NTP_CLIENT_SERVER_LESSONS.md) and
[the supported model](NTP_SUBSET.md) for exact syntax, sources and limitations.

authentication, NTS, full IOS modes or Linux time administration is implemented.
