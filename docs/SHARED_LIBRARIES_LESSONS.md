# Shared-library search and clean-cache handover

Two source-integrated lessons extend the agreed LPIC-1 roadmap after file/link
and process-environment foundations. Their source and development-native teaching checks pass. A separate 281-lab
Fedora candidate is next; the currently verified candidate has 279 labs.
Do not infer complete 102.3 or full certification coverage from these tasks.

| Lab | Independent work | Required foundations |
| --- | --- | --- |
| `lpic1-library-search` | Repair two applications’ complete dependency chains through explicitly simulated per-program settings; preserve system search configuration, cache and an unrelated viewer. | environment inheritance and link handover |
| `lpic1-library-cache-handover` | Diagnose partial temporary overrides, save and rebuild clean search, remove the overrides and retain the viewer’s dependencies. | scoped library investigation |

Introductions teach shared code, names versus paths, search scope, complete
chains and the difference between saving configuration and rebuilding its cache.
The separate brief/preview example uses different directories and programs.
Guided work inserts or fills only example drafts; learners explicitly Save,
Apply, Run, Inspect and Check. A change/observe exercise exposes missing chains
or stale caches. Assignments retain the complete independent requirements and
start unfinished, with optional hints and clear per-application feedback.

The native workspace retains command investigation and real editing interactions.
Scoped tasks keep system configuration behind optional expansion; clean-cache
tasks make the configuration editor prominent. Applied settings, pending drafts,
one-off inspections and clean lookup are intentionally different. Success is
state-based, supports equivalent directory forms, fails partial/broken work and
cannot be earned by the separate example or forged cached observations.
