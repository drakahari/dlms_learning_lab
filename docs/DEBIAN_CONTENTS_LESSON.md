# Find software by its files

2026-11-02source253labs/72units:72CCNA,72LPIC-1,43LPIC-2,66Bash.
`lpic1-package-file-provider` is one substantive extension after the four existing
Debian package tasks, in `debian-package-file-search`. It does not count its
separate workshop or search variations as additional authored labs.

The assignment is to locate a missing executable by its complete repository file
path and install the provider without adding documentation/private-helper
lookalikes, damaging software or losing notes. The package has a different name
from the executable. Existing ownership, repository availability and installed
payload are separate observable facts. A query alone never earns completion.

Introduction explains the record/Contents distinction and shows different gallery
workshop commands/results before practice. Guided practice refreshes an old list,
compares paths, narrows and lists a provider, installs it, deliberately adds a
private helper and repairs the resulting negative requirement. Assignment uses
records data and keeps the provider answer hidden until investigation or requested
help. The existing terminal, actual output/status, file inspector, Check work and
current outcome grader remain the workspace. No worksheet or new UI is introduced.
