Save configuration changes saved text. Start activates it only when stopped;
Reload activates saved text on the running virtual server; Stop removes the
active copy. Out-of-bound or inadmissible action failures retain prior applied
state. A bounded malformed configuration can be saved as raw text without
activation; an invalid Reload retains the previous active copy. Save file writes
only the supplied virtual file and takes effect without a configuration reload.
The optional inspector shows actual active source, never expected grader text.
The optional file picker refuses to discard pending edits silently.
