## Prerequisites and teaching

The integrated unit follows actual `shell-scope` and `shell-case-dispatch` units.
Each lab also names concrete earlier lessons and the prior new assignment where
needed. Missing versus empty, colon choice, read-only fallback/alternate selection,
quoting, literal fallback text and conditional dynamic inheritance are explained
before assessment. `cat --` ends option parsing but a lone `-` still means input.
The report interface therefore rejects that ambiguous source spelling. The task
otherwise accepts quoted leading-dash and spaced names. No utility flag is
silently modeled. The Bash-specific local-variable alternative is optional and
explicitly distinguished from portable shell forms.

Each introduction has five or six short concepts, a runnable example using other
names/data/files, a suggested experiment and a repair. The first example visibly
contrasts an absent LABEL/default with an explicitly empty LABEL in its experiment.
The second experiments with an empty argument; the capstone changes an inherited
display override. Example drafts/results stay separate from the assignment and
cannot earn completion. Challenge retains the complete meaningful task without
unsolicited walkthrough/source. Essential rules are in the task/introduction,
not hidden behind progressive hints.
