`lpic1-echo-path-diagnosis` follows mixed-IP, protocol evidence and listener audit.
The learner compares a nearby reply with a farther LAN failure, fixes the /20
prefix, repairs a default, finds a more-specific /32 detour, and protects the
management interface/routes. An intentionally silent peer is an investigation
control, never a negative grading goal. A valid alternate address ending .255 in
an intermediate /20 octet and a repaired rather than deleted /32 route both pass.

## Model and interaction

`host_echo` adapts the existing finite Echo reducer and Linux host state. It does
not add sockets, subprocesses, host filesystem/network access or a shell evaluator.
Optional `Definition.echo` is source-owned and omitted when absent; old definitions
serialize exactly. Existing State/Profile/Session schemas and evaluator19 stay
unchanged. No existing task gains new objectives. Only the new lesson hides the
old path-inspection Test address and irrelevant resolver editor; it uses its actual
simulated terminal. Other host lessons retain their existing controls/appearance.

Supported forms: `ping -c 1 ADDRESS` and `ping -4 -c 1 ADDRESS`, numeric canonical
IPv4 only, one query to an explicitly supplied peer. Unsupported flags/counts/names
produce a diagnostic. No real ping command is executed. Output says simulated and
never invents measured RTT, TTL, checksums, timeouts, packet loss or DNS behavior.

At most8peers,4return-source prefixes/peer and8positive grading targets. Borrowed
source validation precedes cloning; new vector deserializers enforce limits. The
existing512byte command,64KiB host-state and192KiB definition limits also apply.
Each query has at most two reducer transitions and a fixed small binary payload.
Reports are ephemeral/Serialize-only where appropriate, not deserialized completion
authority. An observation command does not change network state/history.

The existing host probe classifies ONLY outward logical delivery. Explicit source
facts independently select whether the peer replies and which source prefixes its
return path accepts. A generic available-host flag or a TCP listener never invents
an Echo response. No route means no fabricated query. A failed outward query cannot
produce a reply; a delivered request with no response remains unanswered; a reply
can independently fail its return path. This is a finite teaching model, not full
packet forwarding or a Linux kernel.

All graded Echo cases require actual positive matching round trips. Negative/silent
controls cannot satisfy a requirement by breaking the local network. Checks rerun
the reducer from current state; edits invalidate success. Example and assignment
worlds/response facts/drafts are separate. Original progress, favorites and installed
app remain untouched; the separate review candidate uses protected review progress.
