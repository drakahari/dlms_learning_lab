Extract the candidate and drag DLMS Learning Lab.app into Applications (or your user's Applications folder).
Open the application normally. This candidate is unsigned and not notarized: owner installation tests must use Apple's supported signing/security process. Do not disable Gatekeeper or bypass OS controls.
For upgrade, close the application and replace only the .app bundle. Progress stays in the separate macOS application-data folder. For uninstall, remove the .app bundle; keep application data to retain progress. Use Settings → Your data to make a backup first.
Actual macOS installation, reopen, upgrade, accessibility and signing acceptance remain required. A build alone does not establish them.
